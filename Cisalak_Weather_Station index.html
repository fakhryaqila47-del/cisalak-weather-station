Perangkat & sensor pemantauan

Komponen yang membentuk sistem stasiun cuaca mandiri

HARDWARE PROFILE
🧠

ESP32 DEVKIT V3

Mikrokontroler utama

Otak stasiun yang membaca sensor, mengolah data, memberi timestamp, lalu mengirimkan data melalui Wi-Fi.

PUSAT KENDALI IoT
🌡️

BME280 Module

Suhu · kelembapan · tekanan

Mengukur temperatur udara, kelembapan relatif, dan tekanan atmosfer untuk memantau kondisi dasar cuaca.

SENSOR ATMOSFER
🌧️

Tipping Bucket Rain Gauge

Curah hujan

Menghitung tip atau jungkit pada ember takar. Jumlah tip dikonversi menjadi curah hujan dalam milimeter sesuai kalibrasi alat.

SENSOR HUJAN
💨

Anemometer

Kecepatan angin

Mendeteksi putaran baling-baling/cup untuk memperoleh kecepatan angin. Hasil perlu dikalibrasi terhadap spesifikasi alat.

SENSOR ANGIN
🧭

Wind Vane

Arah angin

Menentukan arah datang angin. Pembacaan bergantung pada jenis keluaran vane dan tabel kalibrasi/resistansi yang digunakan.

SENSOR ARAH ANGIN
🌫️

PMS5003 / Plantower

Particulate Matter

Mengukur konsentrasi partikel PM1.0, PM2.5, dan PM10 di udara. Ini merupakan pemantauan kualitas udara, bukan sensor cuaca inti.

KUALITAS UDARA
☀️

BH1750 / GUVA-S12SD

Cahaya / indeks UV

BH1750 mengukur iluminansi dalam lux. GUVA-S12SD merupakan sensor UV analog; hasilnya perlu rangkaian pembacaan dan kalibrasi tersendiri.

RADIASI CAHAYA / UV
🔌

MAX485 Transceiver

Antarmuka komunikasi RS485

Pengubah antarmuka UART ke RS485 untuk komunikasi diferensial dengan perangkat yang mendukung RS485. Bukan sensor pengukur cuaca.

Bagaimana sistem bekerja?

Alur pengukuran dari lingkungan hingga dashboard

Arsitektur stasiun IoT

Sensor mengamati kondisi mikroklimat pada titik pemasangan. ESP32 membaca dan mengemas data untuk dikirim ke server/dashboard melalui jaringan yang tersedia.

Catatan keakuratan: Dashboard ini disiapkan sebagai antarmuka front-end. Saat belum dihubungkan ke endpoint ESP32, angka dan grafik menggunakan data simulasi agar tampilan dapat diuji—bukan hasil pengukuran lapangan. Status akan berubah menjadi LIVE hanya setelah data aktual berhasil diterima dari perangkat. Akurasi bergantung pada pemasangan, interval sampling, kalibrasi, dan kualitas koneksi sensor.
